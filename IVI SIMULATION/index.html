    Journal

      How the signal travels
      1. The driver touches, speaks to, or presses the HMI.
      2. The controller (middleware) receives every command and routes it.
      3. Media, Navigation and Projection services do the feature work.
      4. Navigation merges two independent sources: live GPS and stored map data.
      5. Audio HAL and Display HAL turn service data into speaker and screen output.
      6. The CAN/LIN vehicle network links the controller to the vehicle ECUs.
      7. A paired smartphone can project Android Auto / CarPlay through the HMI.
      About this project

      Conceptual IVI architecture with a browser-based simulation (Module 6). Built with plain HTML, CSS, JavaScript and generated SVG. It runs offline by opening index.html.

      Educational only: no real CAN bus, GPS, Android Automotive, HAL or ECU is involved. All events and timestamps are simulated.
